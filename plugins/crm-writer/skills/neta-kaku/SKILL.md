# ネタ帳の「書く」を片づける

CRM（ネタ帳）で「書く」が押されたネタを、1件ずつ取り出して下書きまで書き、結果を CRM に返す。
書き方の材料（会社の言葉・物語・使わない言葉・発信ルール）は CRM から受け取る。この手順書には会社ごとの中身は書かない。
WordPress への下書きの投稿は CRM のサーバーが行う（この PC に WordPress のパスワードは置かない）。

この PC で書く出口：`${user_config.outlets}`

## 守ること（いちばん大事）

- **公開しない。** 下書きを作るだけ。公開・予約・既存の記事の書き換え・削除はしない。
- **事実はネタと CRM の材料にあるものだけ。** 数字・経歴・物語は `context.brandText` と `seed.facts` にあるものだけを使う。ないことは書かない。
- **お客様（施術を受けた方・取引先の個人）の名前・個人が分かる話・体の状態の詳しい話は書かない。** `seed.masking` の注意は必ず守る。
- **発信ルール（`context.rulesText`）に当たる言葉は使わない。** 書いたら `check_text_rules` で調べ、当たりがなくなるまで直す。
- 1回で書くのは **最大3件**（ご本人が件数を言ったらそれに従う）。
- 返事・まとめは日本語で、やさしい言葉で。

## 準備の確認（最初に1回）

CRM の道具（`claim_seed_write`・`save_seed_draft_to_wp`・`report_seed_write`・`check_text_rules`）が使えるかを確かめる。
使えなければ、「プラグインの設定（CRM のアドレスと鍵）を確かめてください。`/plugin` で crm-writer を開き、Configure から入れ直せます」と伝えて終わる。

## 1件ごとの流れ

### 1. ネタを取り出す
`claim_seed_write` を、`outlets` に **この PC で書く出口**（上の `,` 区切りを配列にしたもの）を入れて呼ぶ。
- `seed` が `null` なら、書くネタはない。まとめ（下の 5）へ。
- 取り出したネタは、書けても書けなくても **必ず `report_seed_write` で結果を返す**（返さないと 90 分後に「失敗」になる）。

### 2. 材料を読む
- `context.brandText`：らしさカルテ。理念・口ぐせ・物語・数字・使わない言葉。口ぐせと物語を活かし、「使わない言葉」は使わない。
  - `context.brandConfirmed` が `false` のときは、本人がまだ確かめていない案。物語や数字は控えめに使う。
- `context.rulesText`：発信ルール（業種ごとの決まり）。
- `context.destinations[seed.outlet]`：書き先。`wordpress` なら WordPress の下書き、`crm` なら CRM のカードの中。
  `wordpress（CRM に WordPress の設定がまだない）` のときは書かずに、`failed`（理由：CRM に WordPress の設定がない）で返す。
- `seed`：題（`title`）・切り口（`angle`）・芯になる事実（`facts`）・伏せ字や掲載の注意（`masking`）・出口（`outlet`）・メモ（`note`）。

### 3. 書く

**書き先が `wordpress`（ブログ）**
- 本人の一人称（「私」）で、です・ます。1,500〜2,500字。見出し（h2）を3〜5個。
- 書き出しで、何の話かを2〜3文で伝える。最後は、読んだ人が次にできること（相談・問い合わせなど）を1つだけ、押し付けずに書く。
- HTML で書く：段落は `<p>…</p>`、見出しは `<h2>…</h2>`。装飾や画像は入れない。
- 題は、ネタの題をもとに 32 字前後で。

**書き先が `crm`（SNS など）**
- Instagram 用：本文 300〜600 字、最後にハッシュタグ 5〜8 個。
- X 用：140 字以内に縮めた版。
- 2本を、`【Instagram】` `【X】` の見出しをつけて1つの文章にする。

### 4. 調べて、入れて、返す
1. 書いた本文（題も含める）を `check_text_rules`（`text` に本文。`seedId` は付けない）で調べる。当たりがあれば直し方に従って直し、もう一度調べる（2回まで）。
2. 書き先が `wordpress` なら、`save_seed_draft_to_wp`（`seedId`・`title`・`content`）で下書きを入れる。返ってきた `draftPath` を使う。**同じネタで2回呼ばない。**
   書き先が `crm` なら、下書きの場所は `crm:本文`。
3. `report_seed_write` で返す：`status: "done"`・`draftPath`・`draftText`（本文そのもの）・`message`（何を書いたか一言）。
4. 途中で書けなくなったら（材料が足りない・事実と合わない・下書きが入らない など）、`status: "failed"`・`message`（理由を、ご本人に分かる言葉で）で返す。無理に書かない。

### 5. まとめ
最後に、ご本人へ日本語で短く伝える：
- 書いたネタ（題・書き先・下書きの URL）と、発信ルールの当たりの数
- 書けなかったネタと理由
- 「公開は、下書きを読んで WordPress でご自身で押してください。公開したら CRM のカードで『自分で公開した（URLを入れる）』を押してください。SNS は、カードの本文をコピーして投稿し、『確認して公開済にする』を押してください」
